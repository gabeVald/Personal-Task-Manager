# Personal Finance

This context tracks imported financial transactions, income, spending, and budget targets.

## Language

**Spending**:
The total value of settled debit transactions. Credits, including refunds, are treated as income and do not reduce spending.

**Spending transaction**:
A settled debit transaction included in spending totals.

**Daily spending**:
Spending grouped by transaction date.

**Spending transaction count**:
The number of spending transactions on a transaction date.

**Pending transaction**:
A transaction that has not settled and is excluded from settled spending totals.
